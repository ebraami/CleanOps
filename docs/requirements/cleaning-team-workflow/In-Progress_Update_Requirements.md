# In-Progress Update Requirements

## 1. Status Transition

When a cleaning team starts working on an assigned report, it can change the report status from:

**Assigned → In Progress**

The `In Progress` status means that the cleaning team has started working on the assigned cleaning request.

## 2. Information the Cleaning Team Can Update

While the report is in progress, the cleaning team can update the following information:

- **Status:** Change the report status to `In Progress`.
- **Notes:** Add short notes about the work being performed.
- **Partial Progress:** Add a short description of the current progress or work completed so far.

## 3. Restrictions

The cleaning team can only update information related to the work on the assigned report.

The cleaning team cannot make the final `Resolved` decision. After the cleaning work is completed, the completion information is reviewed by the operator before the report is resolved.

## 4. Summary

The allowed transition for the cleaning team at this stage is:

**Assigned → In Progress**

The team can update the **status, notes, and partial progress** while working on the report.
